# Payday Planner — releases

Download builds of **Payday Planner**, an Android budget app for semi-monthly paydays, "to be paid" bills and debts.

**[⬇ Download the latest version](../../releases/latest)**: open the `.apk` file on your phone to install it. Requires Android 8.0 or newer.

- If Android asks, allow installing apps from your browser or file manager.
- If Play Protect warns about an unknown app, tap *More details → Install anyway*.
- Updates install over the old version and keep your data. The app also checks here for new versions and offers to update itself.

This repository only hosts release files. The app keeps all your data on your phone.
